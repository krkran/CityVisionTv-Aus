How do I get a token? (2 minutes, once)
  1. Sign in to GitHub with an account that can edit the website repository.
  2. Open Settings → Developer settings → Fine-grained tokens → Generate new token.
  3. Name it CityVision Newsroom, choose an expiry (1 year is fine), and under Repository access pick Only select repositories → CityVisionTv-Aus.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it and paste it above.

Your token is stored only in this browser and is sent only to GitHub. Anyone with the token can edit the site, so keep it private.
